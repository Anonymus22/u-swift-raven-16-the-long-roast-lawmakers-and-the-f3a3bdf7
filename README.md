# The Long Roast: Lawmakers and the File They Cannot Convert

One original satirical sentence, roasting lawmakers who would regulate AI, crypto or the internet but cannot convert a file to PDF. The entry is a single sentence (200 characters): a senator authors a 400-page AI Safety Act, yet still emails his aide asking her to "make this a PDF" — the man writing the rules for the internet's future has never once found the Save As button.
